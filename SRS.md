Purpose and Scope
Purpose

The purpose of the Student Management System is to provide a simple system for managing student records, courses, attendance, and marks or grades. It will allow users to maintain and retrieve student information efficiently.

Scope

In Scope

Adding, editing, and deleting student records.
Storing student name, ID, age, and contact information.
Managing courses and assigning students to courses.
Recording and updating student attendance.
Recording and updating student marks or grades.
Searching and viewing student records.

Out of Scope

Features not listed in the requirements above.
Any additional functionality beyond basic student, course, attendance, marks, and record management.




Functional Requirements

FR-01: The system shall allow users to add, edit, and delete student records.
FR-02: The system shall store student details such as name, ID, age, and contact information.
FR-03: The system shall allow users to manage courses and assign students to courses.
FR-04: The system shall allow users to record and update student attendance.
FR-05: The system shall allow users to record and update student marks or grades.
FR-06: The system shall allow users to search and view student records.




Non-Functional Requirements

NFR-01: The system shall display search results within 2 seconds for up to 1,000 student records.
NFR-02: The system shall allow only authorized users to access and modify student records.
NFR-03: The system shall allow a new user to learn the basic operations within 30 minutes.
NFR-04: The system shall successfully save at least 99% of valid data operations without data loss.




Assumptions

Users will have basic computer skills.
Student and course information will be entered correctly.
The system will be used by a small number of users.
The system will run on a computer that supports Python and SQLite.
Constraints
The system must be built using Python.
The system must use SQLite as its database.
The project must be simple enough to complete within a few weeks.
The system is limited to the six features defined in the requirements.
